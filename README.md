# 📘 Quantitative Finance Projects Portfolio

Welcome to my personal portfolio of projects in **Quantitative Finance**, **Data Analysis**, and **Financial Modeling**.

This repository collects hands-on projects developed in Python, covering key areas such as:
- trading strategy backtesting,
- portfolio optimization,
- macro-financial modeling,
- and derivative pricing.

---

## 🎯 Purpose

The goal of this portfolio is to demonstrate the practical application of quantitative methods to financial problems, combining:
- financial theory,
- statistical modeling,
- and computational implementation.

Each project is designed as a self-contained notebook with both **theoretical intuition** and **code implementation**.

---

## 🧩 Project List

| # | Project | Description |
|:-:|:---------|:-------------|
| 1 | [Finance Starter Kit](./Projects/1.%20Finance%20Starter%20Kit.ipynb) | Introduction to core financial computations: returns, volatility, Sharpe ratio, and drawdowns. |
| 2 | [FX Trading Strategy Backtest](./Projects/2.%20FX%20Trading%20Strategy%20Backtest.ipynb) | Backtesting a rule-based FX trading strategy with performance evaluation and risk metrics. |
| 3 | [Economic Machine](./Projects/3.%20Economic%20Machine.ipynb) | Implementation of a macro-financial framework inspired by Ray Dalio’s “Economic Machine”, modeling economic cycles and relationships. |
| 4 | [Portfolio Optimization](./Projects/4.%20Portfolio%20Optimization.ipynb) | Mean–variance optimization, efficient frontier construction, and portfolio performance analysis using real market data. |
| 5 | [Option Pricing](./Projects/5.%20Option%20Pricing.ipynb) | Pricing European options using both Black–Scholes and Monte Carlo simulation, with theoretical background and numerical comparison. |
