# 📘 Quantitative Finance Projects Portfolio

The full Master’s Thesis is available in the **Thesis** folder of this repository.  
It includes a complete research project on volatility forecasting using econometric and machine learning models.

Welcome to my personal portfolio of projects in **Quantitative Finance**, **Data Analysis**, and **Financial Modeling**.

This repository collects hands-on projects developed in Python and R, covering key areas such as:
- trading strategies,
- portfolio optimization,
- macro-financial modeling,
- derivative pricing,
- and volatility forecasting.

**Note:** The GARCH project is provided as an HTML report.  
GitHub may not render it directly in the browser — please download the file and open it locally for the full interactive version (plots and outputs).

---

## 🎯 Purpose

The goal of this portfolio is to demonstrate the practical application of quantitative methods to financial problems, combining:
- financial theory,
- econometric modeling,
- and computational implementation.

Each project is structured as a self-contained analysis including both **theoretical intuition** and **code implementation**.
